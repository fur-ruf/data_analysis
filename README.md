# data_analysis

Репозиторий содержит цикл лабораторных работ по машинному обучению и анализу данных, выполненных в рамках университетского курса. Каждая работа посвящена изучению конкретного алгоритма или метода на реальных датасетах с полным пайплайном: от очистки данных до оценки качества модели.
